      Why the fetch might fail in the browser
      
The remote server must allow cross-origin requests (CORS) for client-side fetch() to succeed. If you see a CORS error in the console, run the request from a server (server-side proxy) or use a CORS-enabled proxy during development.

      
Example server-side curl (works regardless of CORS):

      
curl "https://sscweb.gsfc.nasa.gov/WS/sscr/2/application.wadl" | xmllint --format -
